# CompositionFactory

> Scene tree watcher and entity lifecycle manager

---

## Overview

**CompositionFactory** is the bridge between Godot's scene tree and Polaris ECS. It monitors the scene tree for nodes with `composition` metadata and automatically creates/destroys entities.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   Godot SceneTree                    CompositionFactory              ECS    │
│                                                                             │
│   ┌─────────────┐   node_added    ┌─────────────────┐             ┌─────┐   │
│   │             │ ───────────────>│                 │  compose()  │     │   │
│   │    Nodes    │                 │  Watches tree   │ ──────────> │world│   │
│   │             │ <───────────────│  Creates/destroys│            │     │   │
│   │             │   node_removed  │  entities       │  decompose()│     │   │
│   └─────────────┘                 └─────────────────┘             └─────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## Responsibilities

| Responsibility | Description |
|----------------|-------------|
| **Watch SceneTree** | Connect to `node_added` and `node_removed` signals |
| **Detect Compositions** | Check nodes for `composition` metadata |
| **Create Entities** | Call `composition->compose(entity, node)` |
| **Destroy Entities** | Call `composition->decompose(entity)` then destruct |
| **Track Mappings** | Maintain node ↔ entity ID mappings via metadata |
| **Collect Existing** | Process nodes already in tree when binding |

---

## Architecture

CompositionFactory is a Godot Node, sibling to PipelineNode in the Polaris autoload:

```
Polaris.tscn (Autoload)
└── Node "Polaris"
    ├── PipelineNode            <-- Runs ECS phases
    └── CompositionFactory      <-- Watches scene tree
```

Both nodes access the ECS world via the `ECSWorld` singleton.

## API

**Location:** `src/polaris/src/core/CompositionFactory.h`

| Method | Description |
|--------|-------------|
| `_ready()` | Attempts auto-bind to SceneTree |
| `_exit_tree()` | Unbinds from SceneTree |
| `bind_to_scene_tree(tree)` | Connect to tree signals, collect existing nodes |
| `unbind_from_scene_tree()` | Disconnect signals, cleanup |

### Internal Handlers

| Handler | Trigger | Action |
|---------|---------|--------|
| `_on_node_added(node)` | `node_added` signal | Check metadata, create entity, call `compose()` |
| `_on_node_removed(node)` | `node_removed` signal | Get entity ID, call `decompose()`, destroy entity |

---

## Scene Tree Binding

CompositionFactory binds to the SceneTree automatically in `_ready()`. If the SceneTree isn't available yet (rare edge case), it defers and retries.

**bind_to_scene_tree()** performs:
1. Skip if running in editor (`is_editor_hint()`)
2. Unbind from previous tree if any
3. Connect to `node_added` and `node_removed` signals
4. Collect existing nodes via recursive traversal

**unbind_from_scene_tree()** disconnects all signals.

---

## Node Handling

### On Node Added

When a node enters the scene tree:

| Step | Action |
|------|--------|
| 1 | Check `has_meta("composition")` |
| 2 | Get `Ref<Composition>` from metadata |
| 3 | Create `flecs::entity` with node's name |
| 4 | Call `composition->compose(entity, node)` |
| 5 | Store entity ID: `node->set_meta("entity_id", id)` |

### On Node Removed

When a node exits the scene tree:

| Step | Action |
|------|--------|
| 1 | Check `has_meta("entity_id")` |
| 2 | Get entity from world by ID |
| 3 | Call `composition->decompose(entity)` if composition exists |
| 4 | Destroy entity: `e.destruct()` |

---

## Metadata Keys

| Key | Type | Set By | Description |
|-----|------|--------|-------------|
| `composition` | `Ref<Composition>` | Developer | The composition resource defining this entity |
| `entity_id` | `uint64_t` | CompositionFactory | The flecs entity ID (for reverse lookup) |

## Lifecycle Sequence

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   COMPOSITION FACTORY LIFECYCLE                                             │
│                                                                             │
│   1. INITIALIZATION                                                         │
│      ┌─────────────────────────────────────────────────────────────────┐   │
│      │ _ready()                                                         │   │
│      │   • _try_auto_bind()                                             │   │
│      │     • Get SceneTree from MainLoop                                │   │
│      │     • bind_to_scene_tree()                                       │   │
│      │       • Connect node_added/node_removed signals                  │   │
│      │       • _collect_existing_nodes() for nodes already in tree      │   │
│      │   • Access world via ECSWorld::get()->world()                    │   │
│      └─────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   2. RUNTIME                                                                │
│      ┌─────────────────────────────────────────────────────────────────┐   │
│      │ For each node_added signal:                                      │   │
│      │   • Check has_meta("composition")                                │   │
│      │   • Get Composition resource                                     │   │
│      │   • Create flecs::entity                                         │   │
│      │   • Call composition->compose(entity, node)                      │   │
│      │   • Store entity_id in node metadata                             │   │
│      │                                                                  │   │
│      │ For each node_removed signal:                                    │   │
│      │   • Get entity_id from metadata                                  │   │
│      │   • Call composition->decompose(entity)                          │   │
│      │   • Destroy flecs::entity                                        │   │
│      └─────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   3. SHUTDOWN                                                               │
│      ┌─────────────────────────────────────────────────────────────────┐   │
│      │ _exit_tree()                                                     │   │
│      │   • unbind_from_scene_tree()                                     │   │
│      │   • Disconnect signals                                           │   │
│      └─────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## Editor Skipping

CompositionFactory skips all operations when running in the Godot editor via `is_editor_hint()` check. This prevents:

- Entities being created while editing scenes
- ECS systems running in the editor
- Performance overhead during level design
