# Entity

> **E** in CELS — Runtime data instances composed of components

---

## Overview

An **Entity** is a unique identifier that groups components together. Entities have no behavior themselves — they're just IDs. All data and logic comes from the components attached to them.

```
Entity = ID + Components
```

In Polaris, entities are created when CompositionFactory detects a node with `composition` metadata. The Composition's `compose()` method adds components to the entity.

## Component Types

| Type | Description | Example |
|------|-------------|---------|
| **Data Components** | Pure data structs | `Health`, `Velocity`, `AIState` |
| **Gd:: Components** | Pointers to Godot nodes (developer-defined) | `Gd::Node`, `Gd::Physics::CharacterController` |
| **Tag Components** | Markers with no data | `Tag::Player`, `Tag::Enemy` |

---

## Data Components

Pure C++ structs that hold game state. No pointers to Godot nodes — just data.

### Definition Pattern

```cpp
struct Health {
    float current = 100.0f;
    float max = 100.0f;

    bool is_alive() const { return current > 0; }
};

```

### Usage

| Operation | API |
|-----------|-----|
| Add with data | `e.set<Health>({ .current = 100, .max = 100 })` |
| Get (read-only) | `const Health* hp = e.get<Health>()` |
| Get (mutable) | `Health* hp = e.get_mut<Health>()` |
| Get (nullable) | `Health* hp = e.try_get_mut<Health>()` |
| Check exists | `if (e.has<Health>())` |
| Remove | `e.remove<Health>()` |

## Gd:: Components

Structs that hold pointers to Godot nodes, bridging ECS logic to the Godot view. **Developers define these** based on their game's needs.

### Pattern

All Gd:: components follow this pattern:

| Member | Purpose |
|--------|---------|
| `NodeType* ptr` | Pointer to Godot node |
| `static T create(Node* root)` | Factory method to create from root node |
| `bool is_valid() const` | Check pointer before use |
| `void unbind()` | Set pointer to nullptr (call in decompose) |

### Example: 3D Node Component

```cpp
namespace Gd {
    struct Node3D {
        godot::Node3D* root = nullptr;

        static Node3D create(godot::Node* n) {
            return { Object::cast_to<godot::Node3D>(n) };
        }

        bool is_valid() const { return root != nullptr; }
        void unbind() { root = nullptr; }

        // Convenience methods
        Vector3 get_position() const;
        void set_position(const Vector3& pos);
    };
}
```

### Example: 2D Node Component

```cpp
namespace Gd {
    struct Node2D {
        godot::Node2D* root = nullptr;

        static Node2D create(godot::Node* n) {
            return { Object::cast_to<godot::Node2D>(n) };
        }

        bool is_valid() const { return root != nullptr; }
        void unbind() { root = nullptr; }

        Vector2 get_position() const;
        void set_position(const Vector2& pos);
    };
}
```

### Usage in Systems

```cpp
world.system<Gd::Node3D, Velocity>()
    .each([](Gd::Node3D& node, Velocity& vel) {
        if (node.is_valid()) {
            node.set_position(node.get_position() + vel.linear);
        }
    });
```

## Tag Components

Empty structs used as markers. No data — just their presence/absence matters.

### Definition Pattern

```cpp
namespace Tag {
    struct Player {};
    struct Enemy {};
    struct Dead {};
}
```

### Usage

| Operation | API |
|-----------|-----|
| Add tag | `e.add<Tag::Player>()` |
| Check tag | `if (e.has<Tag::Player>())` |
| Remove tag | `e.remove<Tag::Dead>()` |

### Query Filtering

```cpp
// Include tag in query
world.each([](Tag::Player, Health& hp) {
    // Only entities with Tag::Player
});

// Exclude tag
world.query_builder<Health>()
    .without<Tag::Dead>()
    .build()
    .each([](Health& hp) {
        // Only living entities
    });
```

## Entity API Reference

### Creating Entities

| Operation | API |
|-----------|-----|
| Create named | `world.entity("Player")` |
| Create anonymous | `world.entity()` |
| Check alive | `e.is_alive()` |
| Destroy | `e.destruct()` |
| Get ID | `e.id()` |

### Component Operations

| Operation | API |
|-----------|-----|
| Set component | `e.set<T>({ ... })` |
| Add tag | `e.add<T>()` |
| Get (read-only) | `e.get<T>()` — returns `const T*` |
| Get (mutable) | `e.get_mut<T>()` — returns `T&` |
| Get (nullable) | `e.try_get_mut<T>()` — returns `T*` or nullptr |
| Has component | `e.has<T>()` |
| Remove | `e.remove<T>()` |

### Chaining

```cpp
e.set<Health>({ 100, 100 })
 .set<Velocity>({})
 .add<Tag::Player>();
```

## Domain-Specific Gd:: Components

Create components for specific Godot node types in your game:

```cpp
namespace Gd::Physics {
    struct CharacterController {
        CharacterBody3D* body = nullptr;

        static CharacterController create(Node* root) {
            return { Object::cast_to<CharacterBody3D>(root) };
        }

        bool is_valid() const { return body != nullptr; }
        void unbind() { body = nullptr; }

        // Convenience methods wrapping CharacterBody3D API
        void move_and_slide() { if (is_valid()) body->move_and_slide(); }
        Vector3 get_velocity() const { return is_valid() ? body->get_velocity() : Vector3(); }
        void set_velocity(const Vector3& v) { if (is_valid()) body->set_velocity(v); }
    };
}

namespace Gd::Animation {
    struct Player {
        AnimationPlayer* player = nullptr;

        static Player create(Node* root, const char* child_name = "AnimationPlayer") {
            return { Object::cast_to<AnimationPlayer>(root->find_child(child_name)) };
        }

        bool is_valid() const { return player != nullptr; }
        void unbind() { player = nullptr; }

        void play(const String& anim) { if (is_valid()) player->play(anim); }
    };
}
```

### Set in compose()

```cpp
void PlayerPawn::compose(flecs::entity e, Node* root) {
    e.set<Gd::Physics::CharacterController>(
        Gd::Physics::CharacterController::create(root)
    );

    e.set<Gd::Animation::Player>(
        Gd::Animation::Player::create(root, "Anim")
    );
}
```

### Cleanup in decompose()

```cpp
void PlayerPawn::decompose(flecs::entity e) {
    if (auto* c = e.try_get_mut<Gd::Physics::CharacterController>()) c->unbind();
    if (auto* a = e.try_get_mut<Gd::Animation::Player>()) a->unbind();
}
```
