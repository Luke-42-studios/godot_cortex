# Entity

> **E** in CELS — Runtime data instances composed of components

---

## Overview

An **Entity** is a unique identifier that groups components together. Entities have no behavior themselves — they're just IDs. All data and logic comes from the components attached to them.

```
Entity = ID + Components
```

In Polaris, entities are created when CompositionFactory detects a node with `composition` metadata. The Composition's `compose()` method adds components to the entity.

---

## Component Types

| Type | Description | Example |
|------|-------------|---------|
| **Gd:: Components** | Pointers to Godot nodes (developer-defined) | `Gd::Node3D`, `Gd::CharacterBody3D`, `Gd::AnimationPlayer` |
| **Data Components** | Pure data structs | `Health`, `Velocity`, `AIState` |
| **Tag Components** | Markers with no data | `Tag::Player`, `Tag::Enemy` |

## Gd:: Components

> **Custom Godot Node Wrappers** - You define these based on your game's needs
>
> **See:** [1.0 Composition.md](1.0%20Composition.md#complete-example-pawn-gd-components) for complete class examples

Structs that hold pointers to Godot nodes, bridging ECS logic to the Godot view.

### Pattern

All Gd:: components follow this pattern:

```cpp
namespace Gd {
    struct ComponentName {
        godot::NodeType* ptr = nullptr;  // or 'root'

        static ComponentName create(godot::Node* n) {
            return { godot::Object::cast_to<godot::NodeType>(n) };
        }

        bool is_valid() const { return ptr != nullptr; }
        void unbind() { ptr = nullptr; }

        // Add convenience methods wrapping Godot API
    };
}
```

### Quick Example

```cpp
namespace Gd {
    struct CharacterBody3D {
        godot::CharacterBody3D* ptr = nullptr;

        static CharacterBody3D create(godot::Node* n) {
            return { godot::Object::cast_to<godot::CharacterBody3D>(n) };
        }

        bool is_valid() const { return ptr != nullptr; }
        void unbind() { ptr = nullptr; }

        void set_velocity(const godot::Vector3& v) {
            if (is_valid()) ptr->set_velocity(v);
        }

        void move_and_slide() {
            if (is_valid()) ptr->move_and_slide();
        }
    };
}
```

### Usage in Systems

**Physics Phase** - Game logic updates velocity:
```cpp
static void apply_velocity(const Velocity& vel, Gd::CharacterBody3D& body) {
    if (!body.is_valid()) return;
    body.set_velocity(vel.linear);
    body.move_and_slide();
}

static void resolve_velocity(Velocity& vel, Gd::CharacterBody3D& body) {
    if (!body.is_valid()) return;
    vel.linear = body.get_velocity();
}

// Registration
w.system<const Velocity, Gd::CharacterBody3D>("ApplyVelocity")
    .kind(physics)
    .each(apply_velocity);

w.system<Velocity, Gd::CharacterBody3D>("ResolveVelocity")
    .kind(physics)
    .each(resolve_velocity);
```

**Process Phase** - Visual updates for smooth rendering:
```cpp
// Use iter signature for delta_time access
static void update_visual_position(flecs::iter& it, size_t i,
                                   Gd::Node3D& node, const Velocity& vel) {
    if (!node.is_valid()) return;
    float dt = it.delta_time();
    Vector3 pos = node.get_position();
    pos += vel.linear * dt;
    node.set_position(pos);
}

// Registration
w.system<Gd::Node3D, const Velocity>("UpdateVisualPosition")
    .kind(process)
    .each(update_visual_position);
```

> **Note:** Physics updates happen at fixed timestep (60hz), visual updates at variable framerate for smooth rendering.

## Entity ↔ Node Lookup

### Node → Entity (Forward Lookup)

When CompositionFactory creates an entity, it stores the ID in node metadata:

```cpp
// CompositionFactory stores this
node->set_meta("entity_id", (uint64_t)entity.id());

// Later, to get entity from node:
uint64_t id = node->get_meta("entity_id");
flecs::entity e = world().entity(id);
```

### Entity → Node (Reverse Lookup)

Systems access Godot nodes through Gd:: components:

```cpp
void my_system(flecs::iter& it, Gd::Node3D* node) {
    for (auto i : it) {
        if (!node[i].is_valid()) continue;

        godot::Node3D* godot_node = node[i].root;  // Direct pointer
        godot_node->set_visible(true);
    }
}
```

## Gd:: Invalidation Guarantees

### When Can `is_valid()` Return False?

| Situation | `is_valid()` | Notes |
|-----------|--------------|-------|
| Normal frame | `true` | Pointer is valid |
| Node queued for deletion | `true` | Still valid until freed |
| After `decompose()` called | `false` | Pointer set to nullptr |
| Entity destroyed | N/A | Component no longer exists |

### Invalidation Timeline

```
┌─────────────────────────────────────────────────────────────────────────────┐
│   INVALIDATION TIMELINE                                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   Node exits tree                                                           │
│       │                                                                     │
│       ▼                                                                     │
│   CompositionFactory::_on_node_removed()                                    │
│       │                                                                     │
│       ├── composition->decompose(entity)                                    │
│       │       └── Gd:: components call unbind()  ←── is_valid() now false   │
│       │                                                                     │
│       └── entity.destruct()  ←── Entity removed from world                  │
│                                                                             │
│   GUARANTEE: Within a single phase tick, Gd:: pointers remain valid.        │
│   Invalidation only happens between frames (during node removal).           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Safety Rules

```cpp
// ALWAYS check validity before use
static void my_system(Gd::Node3D& node) {
    if (!node.is_valid()) return;  // REQUIRED

    // Safe to use node.root here
}

// NEVER store raw Godot pointers across frames
struct BadComponent {
    godot::Node3D* cached_node;  // DANGEROUS - may become invalid
};

// GOOD: Always go through Gd:: component and re-validate every frame
static void good_system(Gd::Node3D& node) {
    if (!node.is_valid()) return;
    // Safe to use node
}
```

## Data Components

Pure C++ structs that hold game state. No pointers to Godot nodes — just data.

### STATE() and CONFIG() Macros

Use `STATE()` and `CONFIG()` macros from `core/ComponentMacros.h` for consistent component declaration:

```cpp
#include "core/ComponentMacros.h"

// CONFIG - serialized, inspector-bound (parameters from editor)
CONFIG(BobConfig) {
    float frequency{2.0f};
    float vertical_cm{8.0f};
    bool enabled{true};
};

// STATE - runtime only, gets .debug() automatically
STATE(BobState) {
    float phase{};
    float current_speed{};
};
```

**STATE()** wraps the struct in `Debuggable<>`, providing a `.debug()` method for conditional debug output. See **[1.0 Composition.md](1.0%20Composition.md#state-and-config-macros-recommended)** for full documentation.

### Definition Pattern

```cpp
struct Health {
    float current = 100.0f;
    float max = 100.0f;

    bool is_alive() const { return current > 0; }
};

struct Velocity {
    godot::Vector3 linear;
    godot::Vector3 angular;
};

enum class AIState : uint8_t {
    Idle, Patrol, Chase, Attack
};

struct AI {
    flecs::entity target;
    float timer = 0.0f;
    float aggro_range = 10.0f;
    AIState state = AIState::Idle;
    uint8_t padding[3];
};
```

> **See:** [examples/pawn_composition.cpp](examples/pawn_composition.cpp) for complete component definitions

### Usage

| Operation | API |
|-----------|-----|
| Add with data | `e.set<Health>({ .current = 100, .max = 100 })` |
| Get (read-only) | `const Health* hp = e.get<Health>()` |
| Get (mutable) | `Health* hp = e.get_mut<Health>()` |
| Get (nullable) | `Health* hp = e.try_get_mut<Health>()` |
| Check exists | `if (e.has<Health>())` |
| Remove | `e.remove<Health>()` |

## Tag Components

Empty structs used as markers. No data — just their presence/absence matters.

### Definition Pattern

```cpp
namespace Tag {
    struct Player {};
    struct Enemy {};
    struct Grounded {};
    struct Dead {};
}
```

### Usage

| Operation | API |
|-----------|-----|
| Add tag | `e.add<Tag::Player>()` |
| Check tag | `if (e.has<Tag::Player>())` |
| Remove tag | `e.remove<Tag::Dead>()` |

### Query Filtering

```cpp
// Include tag in query
world.each([](Tag::Player, Health& hp) {
    // Only entities with Tag::Player
});

// Exclude tag
world.query_builder<Health>()
    .without<Tag::Dead>()
    .build()
    .each([](Health& hp) {
        // Only living entities
    });
```

## Entity API Reference

### Creating Entities

| Operation | API |
|-----------|-----|
| Create named | `world.entity("Player")` |
| Create anonymous | `world.entity()` |
| Check alive | `e.is_alive()` |
| Destroy | `e.destruct()` |
| Get ID | `e.id()` |

### Component Operations

| Operation | API |
|-----------|-----|
| Set component | `e.set<T>({ ... })` |
| Add tag | `e.add<T>()` |
| Get (read-only) | `e.get<T>()` — returns `const T*` |
| Get (mutable) | `e.get_mut<T>()` — returns `T&` |
| Get (nullable) | `e.try_get_mut<T>()` — returns `T*` or nullptr |
| Has component | `e.has<T>()` |
| Remove | `e.remove<T>()` |

### Chaining

```cpp
e.set<Health>({ 100, 100 })
 .set<Velocity>({})
 .add<Tag::Player>();
```
