# Entity

> **E** in CELS — Runtime data instances composed of components

---

## Overview

An **Entity** is a unique identifier that groups components together. Entities have no behavior themselves — they're just IDs. All data and logic comes from the components attached to them.

```
Entity = ID + Components
```

In Polaris, entities are created when CompositionFactory detects a node with `composition` metadata. The Composition's `compose()` method adds components to the entity.

## Component Types

| Type | Description | Example |
|------|-------------|---------|
| **Data Components** | Pure data structs | `Health`, `Velocity`, `AIState` |
| **Gd:: Components** | Pointers to Godot nodes | `Gd::Node`, `Gd::Node2D` |
| **Tag Components** | Markers with no data | `Tag::Player`, `Tag::Enemy` |

---

## Data Components

Pure C++ structs that hold game state. No pointers to Godot nodes — just data.

### Definition Pattern

```cpp
struct Health {
    float current = 100.0f;
    float max = 100.0f;

    bool is_alive() const { return current > 0; }
};

struct Velocity {
    Vector3 linear = Vector3();
    Vector3 angular = Vector3();
};
```

### Usage

| Operation | API |
|-----------|-----|
| Add with data | `e.set<Health>({ .current = 100, .max = 100 })` |
| Get (read-only) | `const Health* hp = e.get<Health>()` |
| Get (mutable) | `Health* hp = e.get_mut<Health>()` |
| Get (nullable) | `Health* hp = e.try_get_mut<Health>()` |
| Check exists | `if (e.has<Health>())` |
| Remove | `e.remove<Health>()` |

## Gd:: Components

**Location:** `src/polaris/src/components/Gd.h`

Structs that hold pointers to Godot nodes, bridging ECS logic to the Godot view.

### Built-in Components

| Component | Description | Auto-set |
|-----------|-------------|----------|
| `Gd::Node` | 3D root node with transform helpers | Yes (by base Composition) |
| `Gd::Node2D` | 2D root node with transform helpers | No (set manually) |

### Gd::Node API

| Member | Type | Description |
|--------|------|-------------|
| `root` | `Node3D*` | Pointer to root node |
| `valid()` | `bool` | Root pointer is valid |
| `get_position()` | `Vector3` | Global position |
| `set_position(Vector3)` | `void` | Set global position |
| `get_rotation()` | `Quaternion` | Rotation |
| `set_rotation(Quaternion)` | `void` | Set rotation |
| `get_basis()` | `Basis` | Global basis matrix |
| `get_forward()` | `Vector3` | -Z direction |
| `get_right()` | `Vector3` | +X direction |
| `get_up()` | `Vector3` | +Y direction |

### Gd::Node2D API

| Member | Type | Description |
|--------|------|-------------|
| `root` | `Node2D*` | Pointer to root node |
| `valid()` | `bool` | Root pointer is valid |
| `get_position()` | `Vector2` | Global position |
| `set_position(Vector2)` | `void` | Set global position |
| `get_rotation()` | `float` | Rotation in radians |
| `set_rotation(float)` | `void` | Set rotation |

### Usage in Systems

```cpp
world.each([](Gd::Node& node, Velocity& vel) {
    if (node.valid()) {
        node.set_position(node.get_position() + vel.linear);
    }
});
```

## Tag Components

Empty structs used as markers. No data — just their presence/absence matters.

### Definition Pattern

```cpp
namespace Tag {
    struct Player {};
    struct Enemy {};
    struct Dead {};
}
```

### Usage

| Operation | API |
|-----------|-----|
| Add tag | `e.add<Tag::Player>()` |
| Check tag | `if (e.has<Tag::Player>())` |
| Remove tag | `e.remove<Tag::Dead>()` |

### Query Filtering

```cpp
// Include tag in query
world.each([](Tag::Player, Health& hp) {
    // Only entities with Tag::Player
});

// Exclude tag
world.query_builder<Health>()
    .without<Tag::Dead>()
    .build()
    .each([](Health& hp) {
        // Only living entities
    });
```

## Entity API Reference

### Creating Entities

| Operation | API |
|-----------|-----|
| Create named | `world.entity("Player")` |
| Create anonymous | `world.entity()` |
| Check alive | `e.is_alive()` |
| Destroy | `e.destruct()` |
| Get ID | `e.id()` |

### Component Operations

| Operation | API |
|-----------|-----|
| Set component | `e.set<T>({ ... })` |
| Add tag | `e.add<T>()` |
| Get (read-only) | `e.get<T>()` — returns `const T*` |
| Get (mutable) | `e.get_mut<T>()` — returns `T&` |
| Get (nullable) | `e.try_get_mut<T>()` — returns `T*` or nullptr |
| Has component | `e.has<T>()` |
| Remove | `e.remove<T>()` |

### Chaining

```cpp
e.set<Health>({ 100, 100 })
 .set<Velocity>({})
 .add<Tag::Player>();
```

## Custom Gd:: Components

Create domain-specific components for your game:

```cpp
// In your game's components header
namespace Gd::Physics {
    struct CharacterController {
        CharacterBody3D* body = nullptr;
        bool valid() const { return body != nullptr; }
    };
}

namespace Gd::Animation {
    struct Player {
        AnimationPlayer* player = nullptr;
        bool valid() const { return player != nullptr; }
    };
}
```

Set in compose():

```cpp
void PlayerPawn::compose(flecs::entity e, Node* root) {
    Composition::compose(e, root);  // Sets Gd::Node

    e.set<Gd::Physics::CharacterController>({
        .body = Object::cast_to<CharacterBody3D>(root)
    });

    e.set<Gd::Animation::Player>({
        .player = Object::cast_to<AnimationPlayer>(root->find_child("Anim"))
    });
}
```
