# Core Classes

> ECSWorld, PipelineNode, and PolarisEngine — The engine's foundation

---

## Overview

| Class | Type | Location | Purpose |
|-------|------|----------|---------|
| `PolarisEngine` | Godot Singleton | `core/Engine.h` | Main coordinator, creates ECSWorld |
| `ECSWorld` | Godot Singleton | `core/ECSWorld.h` | Wraps flecs::world |
| `PipelineNode` | Godot Node | `core/PipelineNode.h` | Drives ECS from frame callbacks |
| `CompositionFactory` | Godot Node | `core/CompositionFactory.h` | Watches SceneTree for compositions |

---

## PolarisEngine

Main entry point that initializes all subsystems.

### API

| Method | Description |
|--------|-------------|
| `get_singleton()` | Static access to engine instance |
| `ecs()` | Get ECSWorld singleton |
| `initialize()` | Called internally to init subsystems |
| `shutdown()` | Called internally on cleanup |
| `create_global_instance()` | Create and register singleton (module init) |
| `destroy_global_instance()` | Destroy singleton (module cleanup) |

### Access

```cpp
PolarisEngine* engine = PolarisEngine::get_singleton();
flecs::world& world = engine->ecs()->world();
```

## ECSWorld

Godot singleton wrapping the flecs world.

### API

| Method | Description |
|--------|-------------|
| `get()` | Static access (C++) |
| `world()` | Get flecs::world reference |
| `get_entity_count()` | Current entity count (GDScript) |
| `progress(delta)` | Manual tick (normally called by PipelineNode) |

### C++ Usage

```cpp
ECSWorld* ecs = ECSWorld::get();
flecs::world& world = ecs->world();

flecs::entity player = world.entity("Player");
player.set<Health>({ 100, 100 });
```

### GDScript Usage

```gdscript
var ecs = Engine.get_singleton("ECSWorld")
print(ecs.get_entity_count())
```

## PipelineNode

Bridges Godot's frame callbacks to ECS.

### API

| Method | Description |
|--------|-------------|
| `_ready()` | Skips processing in editor |
| `_input(event)` | Input pipeline |
| `_physics_process(delta)` | Physics pipeline (fixed timestep) |
| `_process(delta)` | Process + Render pipeline |
| `get_physics_frame()` | Current physics frame count |
| `get_process_frame()` | Current process frame count |
| `set_debug_enabled(bool)` | Toggle debug output |

### Frame Callbacks

| Callback | When | Use For |
|----------|------|---------|
| `_input()` | Input event received | Input handling |
| `_physics_process()` | Fixed timestep (60hz) | Physics, gameplay |
| `_process()` | Every frame (variable) | Rendering, interpolation |

### Editor Detection

PipelineNode disables processing when `is_editor_hint()` is true.

## Singleton Access

### From C++

```cpp
// Direct
ECSWorld* ecs = ECSWorld::get();
flecs::world& world = ecs->world();

// Via engine
PolarisEngine* engine = PolarisEngine::get_singleton();
flecs::world& world = engine->ecs()->world();
```

### From GDScript

```gdscript
var ecs = Engine.get_singleton("ECSWorld")
var polaris = Engine.get_singleton("Polaris")
```

## Lifecycle

```
┌─────────────────────────────────────────────────────────────┐
│ STARTUP                                                     │
│                                                             │
│  1. GDExtension loads                                       │
│  2. polaris_register_classes()                              │
│     └─ PolarisEngine::create_global_instance()              │
│        └─ ECSWorld::create_global_instance()                │
│  3. Godot loads Polaris.tscn autoload                       │
│  4. PipelineNode::_ready()                                  │
│  5. CompositionFactory::_ready()                            │
│     └─ Binds to SceneTree signals                           │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ RUNTIME (every frame)                                       │
│                                                             │
│  PipelineNode::_input()           → Input systems           │
│  PipelineNode::_physics_process() → Physics systems         │
│  PipelineNode::_process()         → Process + Render        │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ SHUTDOWN                                                    │
│                                                             │
│  1. CompositionFactory unbinds                              │
│  2. Entities decomposed as nodes removed                    │
│  3. polaris_unregister_classes()                            │
│     └─ PolarisEngine::destroy_global_instance()             │
│        └─ ECSWorld::destroy_global_instance()               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
