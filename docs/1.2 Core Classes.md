## Polaris::Runtime

The core of Polaris — a Godot Object that owns the flecs world and phase arenas. Managed by `PolarisEngine` singleton.

**Location:** `src/polaris/src/core/Runtime.h`

### Structure

```cpp
namespace Polaris {

struct Arena {
    uint8_t* base;
    size_t offset;
    size_t capacity;
};

enum PhaseType {
    Phase_Input,      // _input()
    Phase_Physics,    // _physics_process()
    Phase_Process,    // _process()
    Phase_Count
};

struct Phase {
    Arena arena;
    flecs::entity id;
};

// Runtime is a Godot Object to enable GDScript access and lifecycle management
class Runtime : public Object {
    GDCLASS(Runtime, Object)

public:
    flecs::world world;
    Phase phases[Phase_Count];
    Arena permanent;

    uint64_t frame;
    uint64_t physics_frame;
};

}
```

### API

| Function | Description |
|----------|-------------|
| `runtime_create()` | Allocate and initialize a new Runtime |
| `runtime_destroy(rt)` | Free Runtime and all arenas |
| `runtime_tick(rt, phase, delta)` | Run systems for a phase, then reset arena |
| `runtime()` | Get global Runtime pointer |
| `world()` | Get flecs::world reference |

### Usage

```cpp
// Global access
Polaris::Runtime* rt = Polaris::runtime();
flecs::world& w = Polaris::world();

// Create entity
flecs::entity player = w.entity("Player");
player.set<Health>({ 100.0f, 100.0f });

// Query
w.each<Health, Gd::Node3D>([](Health& hp, Gd::Node3D& node) {
    // ...
});
```

## PolarisEngine

Main entry point that initializes the Runtime.

**Location:** `src/polaris/src/core/Engine.h`

### API

| Method | Description |
|--------|-------------|
| `get_singleton()` | Static access to engine instance |
| `runtime()` | Get Runtime pointer |
| `initialize()` | Called internally to create Runtime |
| `shutdown()` | Called internally to destroy Runtime |
| `create_global_instance()` | Create and register singleton (module init) |
| `destroy_global_instance()` | Destroy singleton (module cleanup) |

### Access

```cpp
// Via singleton
PolarisEngine* engine = PolarisEngine::get_singleton();
Polaris::Runtime* rt = engine->runtime();

// Direct (preferred)
Polaris::Runtime* rt = Polaris::runtime();
flecs::world& world = Polaris::world();
```

## PipelineNode

Bridges Godot's frame callbacks to ECS.

**Location:** `src/polaris/src/core/PipelineNode.h`

### API

| Method | Description |
|--------|-------------|
| `_ready()` | Skips processing in editor |
| `_input(event)` | Calls `tick(Phase_Input)` — resets arena only |
| `_physics_process(delta)` | Calls `tick(Phase_Physics)` — runs ALL ECS systems via `world.progress()` |
| `_process(delta)` | Calls `tick(Phase_Process)` — resets arena only |
| `get_physics_frame()` | Current physics frame count |
| `get_process_frame()` | Current process frame count |

### Frame Callbacks

| Callback | Phase | Timestep | ECS Systems Run? |
|----------|-------|----------|------------------|
| `_input()` | Phase_Input | Event | No (arena reset only) |
| `_physics_process()` | Phase_Physics | Fixed (60hz) | **Yes — all systems run here** |
| `_process()` | Phase_Process | Variable | No (arena reset only) |

> **Important:** All ECS systems (including those assigned to Phase_Input and Phase_Process) run during `_physics_process()` via a single `world.progress()` call. Phase entities provide ordering, not timing.

### Editor Detection

PipelineNode disables processing when `is_editor_hint()` is true.

## CompositionFactory

Watches the scene tree and creates/destroys entities when nodes with compositions enter/exit.

**Location:** `src/polaris/src/core/CompositionFactory.h`

### API

| Method | Description |
|--------|-------------|
| `_ready()` | Binds to SceneTree signals, collects existing nodes |
| `_on_node_added(node)` | Checks for composition metadata, calls compose() |
| `_on_node_removed(node)` | Calls decompose(), destroys entity |

### How It Works

1. Connects to `SceneTree.node_added` and `node_removed` signals
2. When a node enters with `metadata["composition"]`:
   - Creates a flecs entity
   - Calls `composition->compose(entity, node)`
   - Stores entity ID in `metadata["entity_id"]`
3. When the node exits:
   - Calls `composition->decompose(entity, node)`
   - Destroys the entity

## Access Patterns

### From C++

```cpp
// Direct access (preferred)
Polaris::Runtime* rt = Polaris::runtime();
flecs::world& world = Polaris::world();

// Via engine singleton
PolarisEngine* engine = PolarisEngine::get_singleton();
Polaris::Runtime* rt = engine->runtime();

// Create entity
flecs::entity e = world.entity("Enemy");
e.set<Health>({ 50.0f, 50.0f });
e.add<Tag::Enemy>();
```

### From GDScript

```gdscript
var polaris = Engine.get_singleton("PolarisEngine")
# Limited access - most work done in C++
```

## Lifecycle

```
┌─────────────────────────────────────────────────────────────┐
│ STARTUP                                                     │
│                                                             │
│  1. GDExtension loads                                       │
│  2. polaris_register_classes()                              │
│     └─ PolarisEngine::create_global_instance()              │
│        └─ Runtime()                                         │
│           ├─ Initializes flecs::world                       │
│           ├─ Allocates phase arenas                         │
│           └─ Allocates permanent arena                      │
│  3. Godot loads Polaris.tscn autoload                       │
│  4. PipelineNode::_ready()                                  │
│  5. CompositionFactory::_ready()                            │
│     └─ Binds to SceneTree signals                           │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ RUNTIME (every frame)                                       │
│                                                             │
│  _input(event)                                              │
│  └─ tick(Phase_Input, 0)                                    │
│     └─ arena_reset(input arena)                             │
│                                                             │
│  _physics_process(delta)                                    │
│  └─ tick(Phase_Physics, delta)                              │
│     ├─ world.progress(delta)  ←── ALL ECS systems run here  │
│     └─ arena_reset(physics arena)                           │
│                                                             │
│  _process(delta)                                            │
│  └─ tick(Phase_Process, delta)                              │
│     └─ arena_reset(process arena)                           │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ SHUTDOWN                                                    │
│                                                             │
│  1. CompositionFactory unbinds                              │
│  2. Entities decomposed as nodes removed                    │
│  3. polaris_unregister_classes()                            │
│     └─ PolarisEngine::destroy_global_instance()             │
│        └─ ~Runtime()                                        │
│           └─ Frees all arenas and flecs::world              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
