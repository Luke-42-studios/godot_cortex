# Systems

> How to write game logic as plain functions that process components in bulk

---

## Overview

**Systems** are plain C functions that operate on component data. They run during specific phases and process entities in bulk for performance.

Systems are the **"S"** in ECS — they contain all game logic:
- Player movement
- AI behavior
- Combat
- Animation
- Physics

> **Note:** For phase and pipeline information, see [3. Lifecycle.md](3.%20Lifecycle.md)

---

## What is a System?

A system is a function that:
1. Queries for entities with specific components
2. Processes them in bulk
3. Runs during a specific phase

```cpp
// System function signature
void player_movement(flecs::iter& it,
                     InputState* input,
                     MoveSpeed* speed,
                     Velocity* vel,
                     Gd::Node3D* node)
{
    for (auto i : it) {
        // Process entity i
    }
}
```

## System Types

### Iter-Based Systems (Preferred)

Process entities in bulk for maximum performance.

```cpp
void apply_velocity(flecs::iter& it,
                    Velocity* vel,
                    Gd::CharacterBody3D* body)
{
    for (auto i : it) {
        if (!body[i].is_valid()) continue;
        
        body[i].ptr->set_velocity(vel[i].linear);
        body[i].ptr->move_and_slide();
        vel[i].linear = body[i].ptr->get_velocity();
    }
}
```

**Use for:** Most systems, especially performance-critical ones

### Each-Based Systems

Process one entity at a time. Simpler but slower.

```cpp
void health_regen(flecs::entity e, Health& hp, RegenRate& regen) {
    hp.current = fminf(hp.current + regen.rate, hp.max);
}
```

**Use for:** Simple logic, infrequent updates

## System Registration

Systems must be registered to a phase during initialization.

### Basic Registration

```cpp
void register_movement_systems(Runtime* rt) {
    flecs::entity physics = rt->phases[Phase_Physics].id;

    rt->world.system<Velocity, Gd::CharacterBody3D>("ApplyVelocity")
        .kind(physics)
        .iter(apply_velocity);
}
```

### Registration with Filters

```cpp
// Only process entities with Tag::Player
rt->world.system<InputState>("CapturePlayerInput")
    .kind(rt->phases[Phase_Input].id)
    .with<Tag::Player>()
    .iter(capture_player_input);

// Exclude entities with Tag::Dead
rt->world.system<Health, RegenRate>("HealthRegen")
    .kind(physics)
    .without<Tag::Dead>()
    .iter(health_regen);
```

## Complete Example: Pawn Systems

### PlayerPawn Input System

```cpp
void capture_player_input(flecs::iter& it, InputState* input) {
    godot::Input* godot_input = godot::Input::get_singleton();

    for (auto i : it) {
        input[i].move = godot_input->get_vector(
            "move_left", "move_right", "move_forward", "move_back"
        );
        input[i].jump = godot_input->is_action_just_pressed("jump");
        input[i].attack = godot_input->is_action_just_pressed("attack");
    }
}
```

### PlayerPawn Movement System

```cpp
void player_movement(flecs::iter& it,
                     InputState* input,
                     MoveSpeed* speed,
                     Velocity* vel,
                     Gd::Node3D* node)
{
    for (auto i : it) {
        if (!node[i].is_valid()) continue;

        // Get camera-relative directions
        Vector3 forward = node[i].get_forward();
        Vector3 right = forward.cross(Vector3(0, 1, 0));
        forward.y = 0; forward = forward.normalized();
        right.y = 0; right = right.normalized();

        // Apply input to velocity
        Vector3 dir = forward * input[i].move.y + right * input[i].move.x;
        vel[i].linear.x = dir.x * speed[i].value;
        vel[i].linear.z = dir.z * speed[i].value;

        // Handle jump
        if (input[i].jump && it.entity(i).has<Tag::Grounded>()) {
            vel[i].linear.y = 5.0f;
        }
    }
}
```

### AIPawn State Machine System

```cpp
void ai_state_machine(flecs::iter& it, AI* ai, Gd::Node3D* node) {
    float dt = it.delta_time();

    for (auto i : it) {
        if (!node[i].is_valid()) continue;

        ai[i].timer -= dt;

        switch (ai[i].state) {
            case AIState::Idle:
                if (ai[i].timer <= 0) {
                    ai[i].state = AIState::Patrol;
                    ai[i].timer = 5.0f;
                }
                break;

            case AIState::Chase:
                if (!ai[i].target.is_alive()) {
                    ai[i].state = AIState::Idle;
                } else {
                    auto* target_node = ai[i].target.get<Gd::Node3D>();
                    if (target_node && target_node->is_valid()) {
                        float dist = node[i].get_position().distance_to(
                            target_node->get_position()
                        );
                        if (dist < 2.0f) {
                            ai[i].state = AIState::Attack;
                        }
                    }
                }
                break;

            case AIState::Attack:
                if (ai[i].timer <= 0) {
                    ai[i].state = AIState::Chase;
                }
                break;
        }
    }
}
```

## System Guidelines

### 1. Check Validity

Always check Gd:: components before use:

```cpp
void update_animation(flecs::iter& it, Gd::AnimationPlayer* anim) {
    for (auto i : it) {
        if (!anim[i].is_valid()) continue;  // CRITICAL
        anim[i].ptr->play("walk");
    }
}
```

### 2. Process in Bulk

Use iter-based systems for performance:

```cpp
// GOOD: Bulk processing
void apply_gravity(flecs::iter& it, Velocity* vel) {
    const float gravity = -9.8f;
    float dt = it.delta_time();

    for (auto i : it) {
        if (!it.entity(i).has<Tag::Grounded>()) {
            vel[i].linear.y += gravity * dt;
        }
    }
}
```

### 3. Avoid Allocations

Use phase arenas for temporary data:

```cpp
void ai_pathfinding(flecs::iter& it, AI* ai, Gd::Node3D* node) {
    // Get phase arena
    Arena* arena = &runtime()->phases[Phase_Physics].arena;
    
    // Allocate temp space
    PathNode* nodes = (PathNode*)arena_alloc(
        arena, 256 * sizeof(PathNode), alignof(PathNode)
    );
    
    for (auto i : it) {
        // Use temp space for A* algorithm
    }
    // NO FREE - arena resets automatically
}
```

> **See:** [6. Memory Management.md](6.%20Memory%20Management.md) for arena details

### 4. No Side Effects Outside ECS

Only modify the world through:
- Component data
- Gd:: component calls to Godot
- Entity creation/destruction

```cpp
// GOOD: Modify through components
void damage_system(flecs::iter& it, Health* hp, DamageEvent* dmg) {
    for (auto i : it) {
        hp[i].current -= dmg[i].amount;
    }
}

// BAD: Global state modification
static int global_score = 0;  // DON'T DO THIS
void bad_system(flecs::iter& it) {
    global_score++;  // BAD
}
```

### 5. Early Exit for Invalid Entities

Skip invalid entities early:

```cpp
void process_pawns(flecs::iter& it,
                   Gd::Node3D* node,
                   Health* hp)
{
    for (auto i : it) {
        if (!node[i].is_valid()) continue;  // Skip early
        
        // Process valid entity
    }
}
```

## System Organization

### By Phase

Organize systems by the phase they run in:

```
game/systems/
├── input.cpp       # Phase_Input systems
├── movement.cpp    # Phase_Physics movement
├── combat.cpp      # Phase_Physics combat
├── ai.cpp          # Phase_Physics AI
└── animation.cpp   # Phase_Process animation
```

### Registration Pattern

```cpp
// systems/movement.h
namespace Game::Systems {
    void register_movement_systems(Runtime* rt);
}

// systems/movement.cpp
namespace Game::Systems {

void player_movement(flecs::iter& it, ...) { /* ... */ }
void ai_movement(flecs::iter& it, ...) { /* ... */ }
void apply_gravity(flecs::iter& it, ...) { /* ... */ }
void apply_velocity(flecs::iter& it, ...) { /* ... */ }

void register_movement_systems(Runtime* rt) {
    flecs::entity physics = rt->phases[Phase_Physics].id;

    rt->world.system<InputState, MoveSpeed, Velocity, Gd::Node3D>
        ("PlayerMovement")
        .kind(physics).with<Tag::Player>().iter(player_movement);

    rt->world.system<AI, MoveSpeed, Velocity, Gd::Node3D>
        ("AIMovement")
        .kind(physics).with<Tag::Enemy>().iter(ai_movement);

    rt->world.system<Velocity>("ApplyGravity")
        .kind(physics).iter(apply_gravity);

    rt->world.system<Velocity, Gd::CharacterBody3D>("ApplyVelocity")
        .kind(physics).iter(apply_velocity);
}

}
```

### Main Registration

```cpp
// Called during runtime initialization
void register_all_systems(Runtime* rt) {
    Game::Systems::register_input_systems(rt);
    Game::Systems::register_movement_systems(rt);
    Game::Systems::register_combat_systems(rt);
    Game::Systems::register_ai_systems(rt);
    Game::Systems::register_animation_systems(rt);
}
```

## Execution Order

Systems run in **registration order** within a phase.

```cpp
void register_pawn_systems(Runtime* rt) {
    flecs::entity physics = rt->phases[Phase_Physics].id;

    // These run in this exact order:
    rt->world.system("PlayerMovement").kind(physics).iter(...);   // 1st
    rt->world.system("AIMovement").kind(physics).iter(...);       // 2nd
    rt->world.system("ApplyGravity").kind(physics).iter(...);     // 3rd
    rt->world.system("ApplyVelocity").kind(physics).iter(...);    // 4th
    rt->world.system("CheckGrounded").kind(physics).iter(...);    // 5th
}
```

### Custom Sub-Phases

For fine-grained control, create sub-phases:

```cpp
struct CustomPhases {
    struct {
        flecs::entity input;
        flecs::entity movement;
        flecs::entity apply;
        flecs::entity collision;
    } physics;
};

CustomPhases setup_custom_phases(Runtime* rt) {
    CustomPhases phases;
    flecs::entity physics_root = rt->phases[Phase_Physics].id;

    phases.physics.input = rt->world.entity("Physics.Input")
        .add(flecs::ChildOf, physics_root);

    phases.physics.movement = rt->world.entity("Physics.Movement")
        .add(flecs::ChildOf, physics_root)
        .add(flecs::DependsOn, phases.physics.input);

    phases.physics.apply = rt->world.entity("Physics.Apply")
        .add(flecs::ChildOf, physics_root)
        .add(flecs::DependsOn, phases.physics.movement);

    return phases;
}
```

## Common Patterns

### Movement System

```cpp
void apply_velocity(flecs::iter& it,
                    Velocity* vel,
                    Gd::CharacterBody3D* body)
{
    for (auto i : it) {
        if (!body[i].is_valid()) continue;
        
        body[i].ptr->set_velocity(vel[i].linear);
        body[i].ptr->move_and_slide();
        
        // Read back actual velocity after collision
        vel[i].linear = body[i].ptr->get_velocity();
    }
}
```

### Combat System

```cpp
void check_death(flecs::iter& it, Health* hp) {
    for (auto i : it) {
        if (hp[i].current <= 0) {
            it.entity(i).add<Tag::Dead>();
        }
    }
}
```

### Animation System

```cpp
void update_animation(flecs::iter& it,
                      Velocity* vel,
                      Gd::AnimationPlayer* anim)
{
    for (auto i : it) {
        if (!anim[i].is_valid()) continue;

        float speed = vel[i].linear.length();
        if (speed > 0.1f) {
            anim[i].ptr->play("walk");
        } else {
            anim[i].ptr->play("idle");
        }
    }
}
```

### AI System

```cpp
void ai_target_acquisition(flecs::iter& it, AI* ai, Gd::Node3D* node) {
    for (auto i : it) {
        if (!node[i].is_valid()) continue;
        if (ai[i].state == AIState::Chase) continue;

        Vector3 pos = node[i].get_position();

        // Find nearest player
        runtime()->world.each<Tag::Player, Gd::Node3D>(
            [&](flecs::entity player, Tag::Player, Gd::Node3D& player_node) {
                if (!player_node.is_valid()) return;

                float dist = pos.distance_to(player_node.get_position());
                if (dist < ai[i].aggro_range) {
                    ai[i].target = player;
                    ai[i].state = AIState::Chase;
                }
            }
        );
    }
}
```

## Performance Tips

### 1. Minimize Branching

```cpp
// BAD: Lots of branching
void bad_system(flecs::iter& it, Health* hp) {
    for (auto i : it) {
        if (hp[i].current > 75) {
            // lots of code
        } else if (hp[i].current > 50) {
            // different code
        } else if (hp[i].current > 25) {
            // more code
        } else {
            // even more code
        }
    }
}

// GOOD: Split into separate systems with filters
rt->world.system<Health>("HighHealth")
    .filter([](Health& hp) { return hp.current > 75; })
    .each([](Health& hp) { /* ... */ });

rt->world.system<Health>("MediumHealth")
    .filter([](Health& hp) { return hp.current > 50 && hp.current <= 75; })
    .each([](Health& hp) { /* ... */ });
```

### 2. Cache Lookups

```cpp
// GOOD: Cache common lookups
void process_system(flecs::iter& it, Component* comp) {
    Arena* arena = &runtime()->phases[Phase_Physics].arena;  // Once
    float dt = it.delta_time();  // Once
    
    for (auto i : it) {
        // Use cached values
    }
}
```

### 3. Use Const for Read-Only

```cpp
void read_only_system(flecs::iter& it, const Health* hp, const Velocity* vel) {
    // Compiler can optimize knowing these won't change
}
```

## Summary

| Concept | Description |
|---------|-------------|
| **System** | Plain function that processes component data |
| **Iter-based** | Process entities in bulk (preferred) |
| **Each-based** | Process one entity at a time (simpler) |
| **Registration** | Assign system to phase during initialization |
| **Execution Order** | Systems run in registration order |
| **Arena Usage** | Use phase arenas for temporary allocations |
