# Lifecycle

> **L** in CELS — Pipeline and phase execution

> **Note:** For system implementation details, see [4. Systems.md](4.%20Systems.md)

---

## Overview

The **Lifecycle** layer controls **when** systems run. Polaris aligns with Godot's frame callbacks — `_input`, `_physics_process`, and `_process` — ensuring ECS logic runs at the right time with the right delta.

This document covers:
- **Phases** - Execution buckets tied to Godot callbacks
- **Pipeline** - How Godot drives ECS execution
- **Phase Arenas** - Temporary memory that resets each phase

For **how to write systems**, see [4. Systems.md](4.%20Systems.md).

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   GODOT FRAME                          POLARIS PHASES                       │
│                                                                             │
│   ┌─────────────────┐                  ┌─────────────────┐                  │
│   │ _input(event)   │ ───────────────> │ Phase_Input     │ → arena reset    │
│   └─────────────────┘                  └─────────────────┘                  │
│                                                                             │
│   ┌─────────────────┐                  ┌─────────────────┐                  │
│   │ _physics_process│ ───────────────> │ Phase_Physics   │ → arena reset    │
│   └─────────────────┘                  └─────────────────┘                  │
│                                                                             │
│   ┌─────────────────┐                  ┌─────────────────┐                  │
│   │ _process()      │ ───────────────> │ Phase_Process   │ → arena reset    │
│   └─────────────────┘                  └─────────────────┘                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Phases

Phases map directly to Godot's frame callbacks. Each phase has a dedicated arena for temporary allocations.

| Phase | Godot Callback | Timestep | Arena Size | Use For |
|-------|----------------|----------|------------|---------|
| `Phase_Input` | `_input()` | Event-driven | 64 KB | Input capture, UI events |
| `Phase_Physics` | `_physics_process()` | Fixed (60hz) | 1 MB | Game logic, physics, AI, combat |
| `Phase_Process` | `_process()` | Variable | 512 KB | Animation, interpolation, visuals |

### Phase Definition

```cpp
namespace Polaris {

enum PhaseType {
    Phase_Input,      // _input() - event driven
    Phase_Physics,    // _physics_process() - fixed timestep
    Phase_Process,    // _process() - variable timestep
    Phase_Count
};

struct Phase {
    Arena arena;        // Temporary memory for this phase
    flecs::entity id;   // For system ordering
};

struct Runtime {
    flecs::world world;
    Phase phases[Phase_Count];
    Arena permanent;
    uint64_t frame;
    uint64_t physics_frame;
};

}
```

## Phase Arenas

Each phase has its own arena that **resets automatically** after all systems complete. This provides fast temporary memory for systems.

### Why Phase Arenas?

**Without arenas:**
```cpp
void ai_pathfinding_bad(flecs::iter& it, AI* ai) {
    for (auto i : it) {
        std::vector<PathNode> open_set;   // malloc every frame!
        std::vector<PathNode> closed_set; // malloc every frame!
        // Run A*...
    }  // destructor frees - but this happens 60 times per second!
}

// With 10 AIPawns: 20 malloc/free calls per frame = 1200/second
// Each malloc/free: ~50-200 cycles = 60,000-240,000 cycles wasted
```

**With arenas:**
```cpp
void ai_pathfinding_good(flecs::iter& it, AI* ai, Gd::Node3D* node) {
    Arena* arena = &runtime()->phases[Phase_Physics].arena;
    
    PathNode* open_set = (PathNode*)arena_alloc(arena, 256 * sizeof(PathNode), alignof(PathNode));
    PathNode* closed_set = (PathNode*)arena_alloc(arena, 256 * sizeof(PathNode), alignof(PathNode));
    
    for (auto i : it) {
        // Run A* using scratch space...
    }
    // NO FREE - arena resets automatically at phase end
}

// With 10 AIPawns: 2 arena allocations total = ~10-20 cycles
// 3000-24000x faster!
```

### When to Use Arenas vs Components

**The Rule:** If data needs to **persist beyond the current phase**, use a **component**. If data only lives **during the phase**, use the **phase arena**.

| Scenario | Use | Why |
|----------|-----|-----|
| AI target reference | **Component** | Persists across frames |
| Pathfinding scratch space | **Arena** | Only needed during pathfinding calculation |
| Player health | **Component** | Persists across frames |
| Collision event list | **Arena** | Only needed to process collisions this frame |
| Entity position | **Component** | Persists across frames |
| Sorted entity array | **Arena** | Only needed for this frame's processing |
| Animation state | **Component** | Persists across frames |
| Debug string buffer | **Arena** | Only needed to build UI text this frame |

#### Example: AI Target (Component)

```cpp
// CORRECT: Target persists across frames
struct AI {
    flecs::entity target;  // Stored in component
    AIState state;
};

void ai_target_acquisition(flecs::iter& it, AI* ai, Gd::Node3D* node) {
    for (auto i : it) {
        // Find player and store in component
        ai[i].target = find_nearest_player(node[i].get_position());
    }
}

void ai_chase(flecs::iter& it, AI* ai) {
    for (auto i : it) {
        if (ai[i].target.is_alive()) {
            // Use target from component - persists from previous frame
        }
    }
}
```

#### Example: Pathfinding (Arena)

```cpp
// CORRECT: Scratch space only needed during calculation
void ai_pathfinding(flecs::iter& it, AI* ai, Gd::Node3D* node) {
    Arena* arena = &runtime()->phases[Phase_Physics].arena;
    
    // Temp data - only lives during this system
    PathNode* open_set = arena_alloc(arena, 256 * sizeof(PathNode), alignof(PathNode));
    PathNode* closed_set = arena_alloc(arena, 256 * sizeof(PathNode), alignof(PathNode));
    
    for (auto i : it) {
        // Run A* pathfinding
        // Store RESULT in component, not the scratch data
        ai[i].next_waypoint = calculate_path(open_set, closed_set, ...);
    }
    // open_set and closed_set freed automatically at phase end
}
```

#### Example: Sharing Data Between Phases (Component)

```cpp
// CORRECT: Data shared between Physics and Process phases
struct InterpolationData {
    Vector3 previous_position;
    Vector3 current_position;
};

// Physics phase: Update current position
void physics_update(flecs::iter& it, InterpolationData* interp, Velocity* vel) {
    for (auto i : it) {
        interp[i].previous_position = interp[i].current_position;
        interp[i].current_position += vel[i].linear * dt;
    }
}

// Process phase: Interpolate for smooth visuals
void process_interpolate(flecs::iter& it, InterpolationData* interp, Gd::Node3D* node) {
    for (auto i : it) {
        Vector3 interpolated = lerp(interp[i].previous_position, 
                                    interp[i].current_position, 
                                    alpha);
        node[i].set_position(interpolated);
    }
}
```

#### Anti-Pattern: Storing Arena Pointers

```cpp
// BAD: Storing arena pointer in component
struct BadAI {
    PathNode* path_nodes;  // DANGER: Points to arena memory!
};

void bad_system(flecs::iter& it, BadAI* ai) {
    Arena* arena = &runtime()->phases[Phase_Physics].arena;
    ai[0].path_nodes = arena_alloc(arena, ...);  // BAD!
}
// Arena resets → ai[0].path_nodes is now DANGLING POINTER!

// GOOD: Store the result, not the scratch space
struct GoodAI {
    Vector3 next_waypoint;  // Just the result
};

void good_system(flecs::iter& it, GoodAI* ai) {
    Arena* arena = &runtime()->phases[Phase_Physics].arena;
    PathNode* temp = arena_alloc(arena, ...);  // Temp scratch space
    ai[0].next_waypoint = calculate_path(temp);  // Store result only
}
```

**Location:** `src/polaris/src/core/PipelineNode.h`

```cpp
class PipelineNode : public godot::Node {
    void _input(const Ref<InputEvent>& event) override {
        runtime_tick(runtime(), Phase_Input, 0.0f);
    }

    void _physics_process(double delta) override {
        runtime_tick(runtime(), Phase_Physics, (float)delta);
    }

    void _process(double delta) override {
        runtime_tick(runtime(), Phase_Process, (float)delta);
    }
};
```

### Runtime Tick

```cpp
void runtime_tick(Runtime* rt, PhaseType phase, float delta) {
    // 1. Run all systems assigned to this phase
    rt->world.progress(delta);

    // 2. Reset phase arena for next frame
    arena_reset(&rt->phases[phase].arena);

    // 3. Update frame counters
    if (phase == Phase_Physics) {
        rt->physics_frame++;
    } else if (phase == Phase_Process) {
        rt->frame++;
    }
}
```

**Key Points:**
1. Systems run via `world.progress()`
2. Arena resets **after** all systems complete
3. Frame counters track execution

## Phase Selection Guide

### Phase_Input - Event-Driven

**When to use:**
- Capturing player input
- UI interactions
- Event handling

**Example:**
```cpp
void capture_player_input(flecs::iter& it, InputState* input) {
    godot::Input* godot_input = godot::Input::get_singleton();
    for (auto i : it) {
        input[i].move = godot_input->get_vector(...);
        input[i].jump = godot_input->is_action_just_pressed("jump");
    }
}
```

**Arena usage:** Input event buffers, UI interaction lists

---

### Phase_Physics - Fixed Timestep (60hz)

**When to use:**
- Game logic
- Physics simulation
- AI behavior
- Combat
- Movement

**Example:**
```cpp
void apply_velocity(flecs::iter& it, Velocity* vel, Gd::CharacterBody3D* body) {
    for (auto i : it) {
        if (!body[i].is_valid()) continue;
        body[i].ptr->set_velocity(vel[i].linear);
        body[i].ptr->move_and_slide();
        vel[i].linear = body[i].ptr->get_velocity();
    }
}
```

**Arena usage:** Pathfinding scratch space, spatial query results, damage event lists

---

### Phase_Process - Variable Framerate

**When to use:**
- Visual updates
- Animation
- Interpolation
- Debug rendering
- UI updates

**Example:**
```cpp
void update_animation(flecs::iter& it, Velocity* vel, Gd::AnimationPlayer* anim) {
    for (auto i : it) {
        if (!anim[i].is_valid()) continue;
        float speed = vel[i].linear.length();
        if (speed > 0.1f) {
            anim[i].ptr->play("walk");
        } else {
            anim[i].ptr->play("idle");
        }
    }
}
```

**Arena usage:** Interpolation arrays, debug strings, particle spawn lists

## Frame Context

The Runtime tracks frame counts for debugging and time-based logic.

```cpp
void my_system(flecs::iter& it, Component* comp) {
    Runtime* rt = runtime();
    
    // Process frames since start (variable framerate)
    uint64_t frame = rt->frame;
    
    // Physics frames since start (fixed 60hz)
    uint64_t physics_frame = rt->physics_frame;
    
    // Run every second at 60hz
    if (physics_frame % 60 == 0) {
        // Once per second logic
    }
}
```

## Editor Behavior

PipelineNode disables itself when running in the editor:

```cpp
void PipelineNode::_ready() {
    if (Engine::get_singleton()->is_editor_hint()) {
        set_process(false);
        set_physics_process(false);
        set_process_input(false);
        return;
    }
}
```

**This prevents:**
- ECS systems running during scene editing
- Performance overhead in editor
- Unintended side effects

```
PlayerPawn and AIPawn entities exist in the world

├── _input()
│   ├── Phase_Input systems run
│   │   └── CapturePlayerInput (PlayerPawn only)
│   └── Input arena resets

├── _physics_process(delta)

│   │   ├── AIStateMachine (AIPawn decides action)
│   │   ├── ApplyGravity (all Pawns)
│   │   ├── ApplyVelocity (all Pawns - move_and_slide)
│   │   ├── CheckGrounded (all Pawns)
│   │   └── CheckDeath (all Pawns)
│   └── Physics arena resets (pathfinding data, query results freed)
│
└── _process(delta)
    ├── Phase_Process systems run
    │   └── UpdateAnimation (all Pawns)
    └── Process arena resets (debug strings freed)

## Summary

| Concept | Description |
|---------|-------------|
| **Phase** | Execution bucket tied to Godot callback (_input, _physics, _process) |
| **Phase Arena** | Temporary memory that resets after each phase completes |
| **PipelineNode** | Godot Node that drives ECS from frame callbacks |
| **runtime_tick()** | Runs all systems for a phase, then resets the arena |
| **Fixed Timestep** | Phase_Physics runs at 60hz for deterministic simulation |
| **Variable Framerate** | Phase_Process runs as fast as possible for smooth visuals |
