# Composition

> **C** in CELS — Define entity archetypes and link C++ logic to Godot views

---

## Overview

A **Composition** is a Godot Resource that defines what an entity is made of. It bridges C++ ECS logic with Godot's visual scene tree (the "view"). When a node has a Composition in its metadata, Polaris creates an entity and calls `compose()` to set up components.

```
Node + Metadata["composition"] = Entity
```

---

## Quick Start

### Setting a Composition

| Method | How |
|--------|-----|
| Editor | Inspector → Meta → Add Key: `composition` → Value: `Player.tres` |
| C++ | `node->set_meta("composition", comp_resource)` |
| GDScript | `node.set_meta("composition", preload("res://player.tres"))` |

### Scene Structure

```
CharacterBody3D "Player"         <-- Root node (becomes entity)
    meta:composition = player.tres
    meta:entity_id = 12345       <-- Set by CompositionFactory

|-- MeshInstance3D "Mesh"        <-- Reference via Gd:: components
|-- CollisionShape3D
|-- Skeleton3D "Skeleton"
+-- AnimationPlayer "Anim"
```

### Basic API

**Location:** `src/polaris/src/composition/Composition.h`

| Method | Description |
|--------|-------------|
| `compose(entity, root)` | Add components. Base sets `Gd::Node` + `Gd::Node3D` (for 3D). |
| `decompose(entity)` | Cleanup. Base unbinds `Gd::Node` and `Gd::Node3D`. |

## Config & State Components

Components fall into two categories: **Config** (tunable parameters) and **State** (runtime data).

### STATE() and CONFIG() Macros

Use macros from `core/ComponentMacros.h` for consistent declaration:

```cpp
#include "core/ComponentMacros.h"

// CONFIG - serialized, inspector-bound
CONFIG(BobConfig) {
    float frequency{2.0f};
    float vertical_cm{8.0f};
    int trans{1};              // Tween::TransitionType as int
    int ease{1};               // Tween::EaseType as int
};

// STATE - runtime only, gets .debug() automatically
STATE(BobState) {
    float phase{};
    float current_speed{};
};
```

| Macro | Purpose |
|-------|---------|
| `CONFIG(Name)` | Marker for config structs (pass-through, establishes pattern) |
| `STATE(Name)` | Wraps in `Debuggable<>`, provides `.debug()` method |

### The Config/State Pattern

Always pair Config with State in `compose()`:

```cpp
void PlayerPawn::compose(flecs::entity e, Node* node) {
    Pawn::compose(e, node);

    // Config: Copy from composition (inspector values)
    e.set<BobConfig>(m_bob);

    // State: Fresh instance (default-initialized)
    e.set<BobState>({});
}
```

### Why Separate Them?

| Aspect | Config | State |
|--------|--------|-------|
| Source | Inspector / .tres file | Initialized in compose() |
| Lifetime | Persistent | Transient (reset on respawn) |
| Editor exposure | Yes (properties) | No (internal) |
| Modified by | Setters (live edit) | Systems (every frame) |

### Naming Convention

| Type | Naming | Example |
|------|--------|---------|
| Config | `XxxConfig` | `BobConfig`, `CrouchConfig` |
| State | `XxxState` | `BobState`, `CrouchState` |
| Simple | Just the name | `Health`, `Velocity` |

## Debug Infrastructure

State components declared with `STATE()` get a `.debug()` method for conditional debug output, toggled per-type via the inspector.

### Setup

**Step 1: Add debug accessor to composition class**

```cpp
class EasingDemo : public Composition {
    GDCLASS(EasingDemo, Composition)

protected:
    static void _bind_methods();
    EasingDemoConfig m_config;

public:
    POLARIS_ACCESSORS(EasingDemoConfig, m_config, EASING_DEMO_PROPS)

#ifdef DEBUG_ENABLED
    POLARIS_DEBUG_ACCESSOR(EasingDemoState, easing_demo)
#endif
};
```

**Step 2: Bind debug property in _bind_methods()**

```cpp
void EasingDemo::_bind_methods() {
    POLARIS_BIND(EasingDemo, EASING_DEMO_PROPS)

#ifdef DEBUG_ENABLED
    ADD_GROUP("Debug", "debug/");
    POLARIS_DEBUG_BIND(EasingDemo, easing_demo, "debug/easing_demo")
#endif
}
```

**Step 3: Use state.debug() in systems**

```cpp
static void easing_demo_system(flecs::iter& it, size_t i,
                               const EasingDemoConfig& config,
                               EasingDemoState& state,
                               Gd::Node3D& node) {
    if (!node.is_valid()) return;

    // Debug output (optimized away in release builds)
    if (state.debug()) {
        UtilityFunctions::print("EasingDemo: time=", state.time,
                                " trans=", config.trans);
    }

    // System converts ints to Tween types
    auto trans = static_cast<Tween::TransitionType>(config.trans);
    auto ease = static_cast<Tween::EaseType>(config.ease);
    // ... system logic
}
```

### Key Points

- Debug macros only defined in `DEBUG_ENABLED` — wrap usage in `#ifdef`
- `DebugRegistry` stores flags per-type (not per-entity) — no query overhead
- `state.debug()` returns `false` in release builds (zero runtime cost)
- Toggle via inspector: appears under "Debug" group

## Property Bindings (POLARIS_ACCESSORS)

Use **POLARIS_ACCESSORS** to generate property accessors and **POLARIS_BIND** for ClassDB bindings. This enables .tres serialization AND live runtime editing.

### Architecture

```
┌─────────────────────────────────────────────────────────────────────────────┐
│   POLARIS_ACCESSORS PATTERN                                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ┌─────────────────────┐         ┌─────────────────────┐                   │
│   │  Config Struct      │ sync<T> │  Entity Component   │                   │
│   │  (m_config)         │ ──────> │  (ECS)              │                   │
│   │  Plain POD fields   │         │  Plain POD fields   │                   │
│   └─────────────────────┘         └─────────────────────┘                   │
│            ▲                               │                                │
│            │ setters call sync<T>()        │ systems read                   │
│   ┌────────┴────────────────────┐   ┌──────▼──────────────────┐             │
│   │  Inspector Properties       │   │  Systems convert inline │             │
│   │  (POLARIS_BIND)             │   │  (Units::to_godot)      │             │
│   └─────────────────────────────┘   └─────────────────────────┘             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Full Example

**Step 1: Define X-Macro for property metadata**

```cpp
// X(field, cpp_type, GODOT_TYPE, "path", "hint", Component, member)
#define BOB_PROPS(X, C, M) \
    X(frequency,    float, FLOAT, "bob/frequency",    "", C, M) \
    X(vertical_cm,  float, FLOAT, "bob/vertical_cm",  "", C, M) \
    X(trans,        int,   INT,   "bob/trans", "Linear,Sine,Quint,...", C, M) \
    X(ease,         int,   INT,   "bob/ease",  "In,Out,InOut,OutIn", C, M)
```

**Step 2: Define plain POD structs**

```cpp
CONFIG(BobConfig) {
    float frequency{2.0f};
    float vertical_cm{8.0f};
    int trans{1};
    int ease{1};
};

STATE(BobState) {
    float phase{};
    float current_speed{};
};
```

**Step 3: Use POLARIS_ACCESSORS in composition**

```cpp
class PlayerPawn : public Pawn {
    GDCLASS(PlayerPawn, Pawn)

protected:
    static void _bind_methods();
    BobConfig m_bob;

public:
    // Generates: set_frequency(), get_frequency(), etc.
    POLARIS_ACCESSORS(BobConfig, m_bob, BOB_PROPS)

    void compose(flecs::entity e, Node* node) override;
};
```

**Step 4: Use POLARIS_BIND in _bind_methods()**

```cpp
void PlayerPawn::_bind_methods() {
    ADD_GROUP("Head Bob", "bob/");
    POLARIS_BIND(PlayerPawn, BOB_PROPS)
}
```

### Live Editing

Setters automatically call `sync<T>()` to push changes to ECS:

```cpp
// Generated by POLARIS_ACCESSORS:
void set_frequency(float v) {
    m_bob.frequency = v;
    sync<BobConfig>(m_bob);  // Updates ECS component immediately
}
```

| Use Case | Live Edit? |
|----------|------------|
| Tuning feel (bob, roll) | Yes — instant feedback |
| Movement params | Yes — test without restart |
| Structural changes | No — requires re-compose |

## Gd:: Components

**Location:** `src/polaris/src/components/Gd.h`

Gd:: components hold pointers to Godot nodes, bridging ECS to the view.

### Framework Components

| Component | Description | Auto-set |
|-----------|-------------|----------|
| `Gd::Node` | Generic node reference | Yes (always) |
| `Gd::Node3D` | 3D node with transform helpers | Yes (for 3D nodes) |
| `Gd::Node2D` | 2D node with transform helpers | No (set manually) |

### Common API

| Method | Purpose |
|--------|---------|
| `static T create(Node*)` | Factory method |
| `is_valid()` | Check pointer before use |
| `unbind()` | Set pointer to nullptr (call in decompose) |

### Transform API

**Gd::Node3D:**

| Method | Return |
|--------|--------|
| `get_position()` / `set_position(Vector3)` | Global position |
| `get_rotation()` / `set_rotation(Quaternion)` | Rotation |
| `get_basis()` | Global basis matrix |
| `get_forward()` / `get_right()` / `get_up()` | Direction vectors |

### Custom Gd:: Components

```cpp
namespace Gd {
    struct Camera3D {
        godot::Camera3D* root = nullptr;

        static Camera3D create(godot::Node* n) {
            return { godot::Object::cast_to<godot::Camera3D>(n) };
        }
        bool is_valid() const { return root != nullptr; }
        void unbind() { root = nullptr; }
    };
}
```

### Node Discovery

| Pattern | Use Case |
|---------|----------|
| `Object::cast_to<T>(root)` | Root is target type |
| `root->find_child("Name")` | Find child by name |
| `Object::cast_to<T>(root->find_child("Name"))` | Find + cast |

## Implementing a Composition

### Class Definition

```cpp
class PlayerPawn : public Pawn {
    GDCLASS(PlayerPawn, Pawn)

protected:
    static void _bind_methods();
    BobConfig m_bob;
    CrouchConfig m_crouch;

public:
    POLARIS_ACCESSORS(BobConfig, m_bob, BOB_PROPS)
    POLARIS_ACCESSORS(CrouchConfig, m_crouch, CROUCH_PROPS)

#ifdef DEBUG_ENABLED
    POLARIS_DEBUG_ACCESSOR(BobState, bob)
    POLARIS_DEBUG_ACCESSOR(CrouchState, crouch)
#endif

    void compose(flecs::entity e, Node* root) override;
    void decompose(flecs::entity e) override;
};
```

### compose() Pattern

```cpp
void PlayerPawn::compose(flecs::entity e, Node* node) {
    Pawn::compose(e, node);  // Sets Gd::Node + Gd::Node3D

    // Config components (from inspector)
    e.set<BobConfig>(m_bob);
    e.set<CrouchConfig>(m_crouch);

    // State components (fresh)
    e.set<BobState>({});
    e.set<CrouchState>({});

    // Tags
    e.add<Tag::Player>();
}
```

### decompose() Pattern

```cpp
void PlayerPawn::decompose(flecs::entity e) {
    // Unbind custom Gd:: components
    if (auto* c = e.try_get_mut<Gd::Camera3D>()) c->unbind();

    Pawn::decompose(e);  // Unbinds Gd::Node + Gd::Node3D
}
```

### _bind_methods() Pattern

```cpp
void PlayerPawn::_bind_methods() {
    ADD_GROUP("Head Bob", "bob/");
    POLARIS_BIND(PlayerPawn, BOB_PROPS)

    ADD_GROUP("Crouch", "crouch/");
    POLARIS_BIND(PlayerPawn, CROUCH_PROPS)

#ifdef DEBUG_ENABLED
    ADD_GROUP("Debug", "debug/");
    POLARIS_DEBUG_BIND(PlayerPawn, bob, "debug/bob")
    POLARIS_DEBUG_BIND(PlayerPawn, crouch, "debug/crouch")
#endif
}
```

## Designer Units

Compositions store values in **designer-friendly units**. Systems convert to **Godot units** when reading config.

**Location:** `src/polaris/src/core/Units.h`

### Domain Rules

| Domain | Designer Unit | Godot Unit | Why |
|--------|---------------|------------|-----|
| Speed | HU/s | m/s | "320 = walk" is universal |
| Distance (large) | HU | meters | Player height = 72 HU |
| Distance (small) | cm | meters | "2.5 cm bob" is tangible |
| Rotation | degrees | radians | Everyone knows 90° |
| Multiplier | % (0-100) | 0.0-1.0 | "50% speed" is clear |

### Conversion in Systems

```cpp
#include "core/Units.h"

static void head_bob_system(const BobConfig& config, BobState& state, ...) {
    using namespace Units;

    // Convert cm → meters
    float amp = Distance::cm_to_godot(config.vertical_cm);  // 2.5 → 0.025

    // Convert int → enum
    auto trans = static_cast<Tween::TransitionType>(config.trans);
    auto ease = static_cast<Tween::EaseType>(config.ease);

    // ... use converted values
}
```

### GoldSrc Quick Reference

| Property | Source (HU) | Godot (m) |
|----------|-------------|-----------|
| Walk speed | 320 HU/s | 8.128 m/s |
| Run speed | 400 HU/s | 10.16 m/s |
| Gravity | 800 HU/s² | 20.32 m/s² |
| Player height | 72 HU | 1.8288 m |
| Crouch height | 36 HU | 0.9144 m |

## Summary

1. Attach `Composition` resource to node via metadata
2. CompositionFactory creates entity, calls `compose()`
3. Use `CONFIG()` for inspector-bound parameters
4. Use `STATE()` for runtime data (gets `.debug()` method)
5. Use `POLARIS_ACCESSORS` + `POLARIS_BIND` for property bindings
6. Systems query Config/State components and do all conversions
